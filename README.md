# Abandoned Baby Camarilla R3/S3 Scanner V4

Only Camarilla R3 and S3 are used.

Bullish:
D1 long red -> D2 doji gaps below D1 -> D3 long green gaps above D2 -> D3 closes above D1 open.
The pattern must test Camarilla S3 and D3 must close above S3.

Bearish:
D1 long green -> D2 doji gaps above D1 -> D3 long red gaps below D2 -> D3 closes below D1 open.
The pattern must test Camarilla R3 and D3 must close below R3.

EMA, PP, R1/R2 and S1/S2 are completely removed.

Camarilla:
R3 = Previous Close + 1.1 * (Previous High - Previous Low) / 4
S3 = Previous Close - 1.1 * (Previous High - Previous Low) / 4
